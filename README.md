Ghost Game Template: a three.js (WebGL2) starter scene for browser 3D games, no build step. It needs a web server, so opening index.html from disk will not work: use GitHub Pages.
Live: https://ghostchatdev.github.io/ghost-game-template./ (after GitHub Pages is switched on for this repository)
Copy this repo to start your own game.
